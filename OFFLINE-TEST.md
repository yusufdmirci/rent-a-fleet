# Offline Test Checklist

- [ ] Open the app once with internet access
- [ ] Wait for the service worker to activate
- [ ] Reload once while online
- [ ] Set the network to offline
- [ ] Reload the app
- [ ] Confirm the main game loads
- [ ] Accept or complete a rental
- [ ] Reload again
- [ ] Confirm local progress remains
- [ ] Clear browser storage and confirm expected reset behavior
- [ ] Re-test on Android and iOS browsers
